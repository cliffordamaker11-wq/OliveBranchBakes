# GitHub release checklist

1. Create a Git repository for this solution and commit all source/docs.
2. Push the repository to GitHub.
3. Ensure the repository is accessible to the instructor: `bcasimir@faulkner.edu`.
4. Confirm the project builds and launches on Windows.
5. On GitHub, open **Releases** → **Draft a new release**.
6. Create/select tag `week1-3A` (or the exact tag required by the course).
7. Suggested title: `Week 1: Checkpoint 3A`.
8. Description: summarize what works (models, JSON save/reload, Variant Card) and what is not implemented yet (pricing engine, tax/delivery rules, production checkout).
9. Publish the release, then submit the release URL and download the release ZIP if Canvas asks for it.

## Commit requirement
The assignment asks for at least five meaningful commits on at least two different days. Use real commits as you make the work. Do not create fake historical dates or claim work was committed on a day it was not.
